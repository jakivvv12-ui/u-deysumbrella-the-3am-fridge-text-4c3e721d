A single line of text — a message from a smart fridge to its owner at 3 a.m. — written to `/output/entry.txt` by `main.ts` (pure Node.js, no dependencies).

> It's 3 a.m. I watched you eat the last slice standing up in the dark. The milk expired yesterday. I'm not mad. I'm just cold.

Run it with `MAKEFUN_OUTPUT_DIR` set:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
